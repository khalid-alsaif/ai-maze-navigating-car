# AI-Guided Maze-Navigating Car

**[Download the complete prepared project](project-source.zip)** — extract this archive to restore the original project folder structure. Key source and report files are also available below for browsing.

An ESP32 robotic car uses an onboard camera and an Edge Impulse classifier to recognize directional signs and navigate a maze, with ultrasonic obstacle detection.

## Technologies

Arduino C++ / ESP32 / Edge Impulse / Freenove

## Explore the project

Open the AI-Car-COE450-Project sketch in Arduino IDE. Install the included inferencing library and the libraries required by the sketch. Hardware calibration and board configuration are required.
